# TB WGS Analysis

## Overview
This repository contains scripts and documentation
for Whole Genome Sequencing (WGS) analysis of
Mycobacterium tuberculosis by BGSI Hub Tuberculosis RSUP Persahabatan.

## Objectives
- Perform FASTQ quality control.
- Identify antimicrobial resistance genes.
- Conduct phylogenetic analysis.

## Tools
- FastQC
- fastp
- TB-Profiler
- AMRFinderPlus
- ResFinder

## Workflow
1. Quality Control
2. Read Trimming
3. Drug Resistance Prediction
4. AMR Detection
5. Phylogenetic Analysis
